# 🚀 Cyber Attack Prediction using Machine Learning

## 📌 Project Overview

This project focuses on predicting cyber attacks using Machine Learning techniques integrated with a Django web application. The system analyzes patterns in data and provides predictions to enhance cybersecurity awareness and prevention.

---

## 🎯 Objectives

* Predict potential cyber attacks using ML models
* Provide a user-friendly web interface using Django
* Improve security decision-making with data-driven insights

---

## 🛠️ Technologies Used

* Python
* Django Framework
* Machine Learning (Scikit-learn / Pandas / NumPy)
* SQLite Database
* HTML, CSS (Frontend)

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
```

### 2️⃣ Create virtual environment

```
python -m venv venv
venv\Scripts\activate   # Windows
```

### 3️⃣ Install dependencies

```
pip install -r requirements.txt
```

### 4️⃣ Run migrations

```
python manage.py migrate
```

### 5️⃣ Run the server

```
python manage.py runserver
```
